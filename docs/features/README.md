# Планируемые фичи

Каждая фича описывается в отдельном файле формата `<slug>.md`.

## Статусы

| Статус | Значение |
|---|---|
| `planned` | Описана, ждёт очереди |
| `in progress` | Взята в разработку |
| `done` | Реализована |

## Шаблон файла

```markdown
# <Название фичи>

**Статус:** planned

## Зачем

Короткое объяснение проблемы или потребности пользователя.

## Поведение

Что именно должна делать фича — с точки зрения пользователя.
Используй список или сценарий "дано / когда / тогда".

## Критерии готовности

- [ ] ...
- [ ] E2E-тест покрывает основной сценарий

## Технические заметки

Опциональный раздел: ограничения, зависимости, черновик реализации.
```
