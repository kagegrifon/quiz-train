# Переключение темы (тёмная / светлая)

**Статус:** planned

## Зачем

Пользователи работают в разных условиях освещения. Тёмная тема снижает нагрузку на глаза
при работе вечером и является стандартным ожиданием от современного веб-приложения.

## Поведение

- В шапке каждой страницы есть кнопка-переключатель темы (иконка солнца / луны).
- По умолчанию используется системная тема пользователя (`prefers-color-scheme`).
- Выбор сохраняется в `localStorage` и восстанавливается при следующем визите.
- Переключение мгновенное, без перезагрузки страницы.

### Сценарий

**Дано:** пользователь открыл приложение
**Когда:** нажимает кнопку переключателя
**Тогда:** тема меняется на противоположную и сохраняется в localStorage

**Дано:** пользователь ранее выбрал тёмную тему
**Когда:** открывает приложение повторно
**Тогда:** тёмная тема применяется сразу, без мигания

## Критерии готовности

- [ ] Кнопка-переключатель видна на всех страницах (Start, Quiz, Results, Stats)
- [ ] Системная тема применяется по умолчанию
- [ ] Выбор пользователя сохраняется в localStorage и восстанавливается
- [ ] Нет мигания при загрузке страницы (flash of wrong theme)
- [ ] Подсветка правильных/неправильных ответов корректно отображается в обеих темах
- [ ] E2E-тест: переключение темы, сохранение в localStorage

## Технические заметки

- Mantine имеет встроенную поддержку тем через `MantineProvider` + `ColorSchemeScript`.
  `ColorSchemeScript` в `<head>` устраняет мигание при загрузке.
- `useMantineColorScheme()` — хук для переключения и чтения текущей темы.
- CSS-переменные Mantine автоматически меняются при смене темы — кастомные стили
  в `.module.css` должны использовать `var(--mantine-color-*)` вместо хардкод-цветов.
- Текущие `.optionCorrect` / `.optionWrong` используют `light-dark()` — уже готовы к тёмной теме.
- Ключ localStorage для темы: `programmingQuizTheme`.
