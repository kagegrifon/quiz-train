# Оптимизация бандла

**Статус:** done

## Зачем

При сборке Vite выдавал предупреждение о чанке >500 kB. Всё приложение собиралось в один файл `index.js` весом **1 248 kB** (gzip: 418 kB), что замедляло первую загрузку и исключало браузерное кеширование вендоров.

## Поведение

- Бандл разбит на отдельные чанки: vendor-react, vendor-mantine, vendor-router, vendor-markdown + чанки страниц
- Страницы грузятся лениво (по переходу на маршрут), не при первой загрузке
- Предупреждение Vite о размере чанка исчезло
- После `npm run build` генерируется `dist/stats.html` — интерактивная карта состава бандла

## Технические заметки

- Главный вклад в размер давал `react-syntax-highlighter`: при импорте `Prism` подтягивались все 197 языков (~600 kB). `PrismLight` — bare-bones версия без языков, языки регистрируются вручную.
- `manualChunks` задаётся функцией (не объектом) — требование rolldown-совместимого Vite 8.
- `withSuspense(Component)` — HOC-обёртка в `router.tsx` для каждого lazy-компонента. `fallback={null}` — пустой экран во время загрузки (переходы мгновенные на практике).
- `visualizer` настроен с `open: false` чтобы не открывать браузер автоматически при каждой сборке. Открывать вручную: `dist/stats.html`.
