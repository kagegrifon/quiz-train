# Code Quality Gates

**Статус:** done

## Зачем
В проекте накапливался мёртвый код (неиспользуемые файлы, экспорты), а линтер запускался только вручную. Нужны автоматические барьеры: проверка при коммите и инструмент для детекции неиспользуемого кода.

## Поведение
- `git commit` автоматически запускает ESLint на staged `.ts`/`.tsx` файлах через `lint-staged`. При ошибках или предупреждениях коммит блокируется.
- `npm run knip` — ручная проверка на мёртвый код: неиспользуемые файлы, экспорты, зависимости.

## Технические заметки
- Конфигурация Knip: `knip.config.ts` в корне проекта. Entry points: `src/main.tsx`, `e2e/**/*.ts`.
- `lint-staged` запускает ESLint только на staged файлах — быстро даже в большом проекте.
- Knip **не** добавлен в pre-commit (медленный полный анализ), запускается вручную при рефакторинге.
- TypeScript (`noUnusedLocals`, `noUnusedParameters`) уже был включён в `tsconfig.app.json` — дополняет Knip на уровне компилятора.
