# Выгрузка квиза в файл

**Статус:** done

## Зачем

Пользователь может скачать любой квиз (встроенный или загруженный) в виде JSON-файла —
чтобы сохранить, отредактировать или поделиться им. Формат совпадает с форматом загрузки,
квиз можно импортировать обратно без изменений.

## Поведение

- На каждой карточке квиза в каталоге есть кнопка **«Скачать»** (иконка `IconDownload`).
- Нажатие инициирует скачивание JSON-файла без перехода на другую страницу.
- Имя файла формируется из заголовка квиза: пробелы → дефисы, строчные буквы, `.json`.
  Пример: `«Основы JavaScript»` → `osnovy-javascript.json`.
- Поле `id` в экспорте **отсутствует** — оно вычисляемое, не является частью пользовательских данных.
- Экспортированный файл корректно импортируется обратно через «Загрузить квиз из файла».

### Сценарий

**Дано:** пользователь на странице каталога
**Когда:** нажимает «Скачать» на карточке квиза
**Тогда:** браузер скачивает `<slug>.json` с содержимым квиза

## Критерии готовности

- [ ] Кнопка «Скачать» есть на карточке каждого квиза (встроенного и пользовательского)
- [ ] Скачанный файл не содержит поле `id`
- [ ] Имя файла соответствует заголовку квиза
- [ ] Скачанный файл можно импортировать обратно без ошибок валидации
- [ ] E2E-тест: нажать «Скачать» → проверить атрибут `download` и имя файла

## Технические заметки

### Утилита скачивания

```ts
// shared/lib/download-json.ts
export function downloadJson(filename: string, data: unknown): void {
  const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
  const url = URL.createObjectURL(url);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}

export function slugify(title: string): string {
  return title
    .toLowerCase()
    .replace(/ё/g, 'e')
    .replace(/[^a-zа-я0-9]+/gi, '-')
    .replace(/^-+|-+$/g, '');
}
```

### Формат экспорта

`id` и `questions[].id` не включаются в экспорт — при импорте они генерируются автоматически.

```ts
// Перед скачиванием:
const { id: _quizId, questions, ...rest } = quiz;
const exportData = {
  ...rest,
  questions: questions.map(({ id: _qId, ...q }) => q),
};
```
