# Quiz Train

[**Открыть демо →**](https://kagegrifon.github.io/quiz-train/) · [🇬🇧 English version](README.md)

> Веб-приложение для прохождения квизов по программированию с настраиваемым
> режимом проверки ответов, частичными баллами и статистикой попыток.

## Живая версия

**[https://kagegrifon.github.io/quiz-train/](https://kagegrifon.github.io/quiz-train/)**

В приложении встроены два квиза — JS Basics и TS Basics. Можно также загрузить
свой квиз в формате JSON и экспортировать любой квиз обратно в JSON.

## Возможности

- **Вопросы в Markdown** — вопросы и варианты ответов поддерживают полный Markdown, включая блоки кода с подсветкой синтаксиса
- **Один и несколько ответов** — вопросы типа radio (один ответ) и checkbox (несколько ответов)
- **Два режима проверки:**
  - `afterAnswer` — подсветка правильного/неправильного сразу после нажатия «Ответить»; ответ фиксируется
  - `onFinish` — свободная навигация между вопросами, результаты видны только на странице итогов
- **Частичные баллы** — для multi-select вопросов очки начисляются пропорционально правильно выбранным вариантам
- **Таймер обратного отсчёта** — опциональный лимит времени; квиз завершается автоматически при 0
- **Загрузка и экспорт квизов** — загрузить JSON-квиз с диска; экспортировать встроенный или пользовательский квиз
- **История попыток** — все попытки сохраняются в `localStorage` с очками, процентом, временем и снимком настроек
- **Тёмная и светлая тема** — переключатель в шапке, сохраняется между сессиями

## Архитектура — Feature-Sliced Design

Проект следует методологии [Feature-Sliced Design](https://feature-sliced.design/) — слоистая архитектура, где каждый слой может импортировать только из нижележащих слоёв.

| Слой       | Директория      | Содержимое                                                  |
|------------|-----------------|-------------------------------------------------------------|
| `app`      | `src/app/`      | Роутер, провайдеры, глобальный layout                       |
| `pages`    | `src/pages/`    | Полные страницы: Start, Quiz, Results, Stats, Settings      |
| `widgets`  | `src/widgets/`  | Сложные UI-блоки: QuestionView, AppHeader                   |
| `entities` | `src/entities/` | Бизнес-сущности: Question, Quiz, встроенные квизы           |
| `shared`   | `src/shared/`   | Переиспользуемое: скоринг, хранилище, UI-примитивы          |

Каждый слайс экспортирует только через публичный API — `index.ts`. Алиас `@/` указывает на `src/`.

## Технические особенности

- **Состояние квиза в URL** — TanStack Router валидирует все search params на уровне типов; конфигурация квиза (режим reveal, таймер, флаги подсветки) хранится в URL, что делает результаты доступными по ссылке
- **Два режима reveal с частичными баллами** — `afterAnswer` фиксирует каждый ответ индивидуально; скоринг multi-select: `очки × (правильно выбрано / всего правильных)`, без штрафа за лишние варианты
- **E2E-тесты на Playwright** — покрывают каталог, прохождение квиза, разбор результатов, загрузку/экспорт, таймер, переключение темы
- **Автоматические проверки перед коммитом** — Husky + lint-staged запускают ESLint с флагом `--max-warnings=0` на staged-файлах; коммит блокируется при любом предупреждении
- **Оптимизация бандла** — code splitting по маршрутам + `react-syntax-highlighter/prism-light` (регистрируются только используемые языки) сокращают начальный чанк

## Запуск проекта

**Требования:** Node.js 20+

```bash
git clone https://github.com/kagegrifon/quiz-train.git
cd quiz-train
npm install
npm run dev
```

Приложение запустится на `http://localhost:5173`.

## Команды

| Команда            | Описание                                           |
|--------------------|----------------------------------------------------|
| `npm run dev`      | Dev-сервер с HMR                                   |
| `npm run build`    | Проверка типов + production-сборка                 |
| `npm run preview`  | Предпросмотр production-сборки локально            |
| `npm run e2e`      | Запуск E2E-тестов Playwright (headless)            |
| `npm run e2e:ui`   | Интерактивный режим Playwright                     |
| `npm run lint`     | Полная проверка ESLint по всему проекту            |
| `npm run knip`     | Поиск неиспользуемых файлов, экспортов, зависимостей |
| `npm run deploy`   | Сборка + публикация на GitHub Pages                |
